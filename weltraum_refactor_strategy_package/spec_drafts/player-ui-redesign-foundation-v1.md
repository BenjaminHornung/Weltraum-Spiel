# Spec Draft: player-ui-redesign-foundation-v1

## Proposal

Create player-facing UI foundations for ShipFlight, Navigation, Map, Surface,
Builder and Debug separation.

## Scope

- Input mode state model
- HUD ViewModels
- Navigation status panel states
- Debug-vs-player policy
- Screenshot evidence matrix

## Non-goals

- Full art pass
- Full settings menu
- Replacing all uGUI in one step
- Changing autopilot logic

## Acceptance

- Active mode visible.
- Next player action visible.
- Debug-only UI not required for player task.
- Screenshot evidence for common aspects.
