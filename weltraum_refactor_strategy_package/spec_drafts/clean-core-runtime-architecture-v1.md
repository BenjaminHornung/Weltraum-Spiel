# Spec Draft: clean-core-runtime-architecture-v1

## Proposal

Create a clean product architecture under `Assets/_Weltraum` while freezing the
existing Prototype runtime as legacy/reference.

## Scope

- Folder skeleton
- Assembly definitions
- Namespace/dependency rules
- AGENTS.md and PLANS.md integration
- Scene manifest template
- Legacy boundary docs

## Non-goals

- No gameplay behavior replacement
- No Autopilot rewrite in this change
- No UI redesign in this change

## Acceptance

- Project compiles.
- Prototype still boots.
- New skeleton and docs exist.
- Agents have clear ownership rules.
