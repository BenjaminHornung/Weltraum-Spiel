# Gate C: persistent Terrain data and Native subset ownership

Reuse the existing Main Terrain-root derivative and exact Support algorithm; do not move its same CPU work onto the simulation thread. The new variant uses the completed immutable subset builder for Main Support fragments and a per-Physics-session verified ancestor for Native fragment creation. The first request carries a bounded reconstruction-input record (no persistence string); Native performs full general admission once, checks its canonical content hash and normative frame/material contract, then retains its fully immutable graph. Later requests carry only ancestor/expected-child digest and the existing exact cells/collider claim. Native derives the child from actual cached ancestor cells, verifies its full canonical digest, and performs the existing mass/connectivity/collider admission.

The live encodeStructuralObject + encoder self-decode + Native decodeStructuralObject roundtrip is absent. Public persistence remains unchanged. Main/Native ancestor graphs are not cross-thread capabilities: structured-cloned cold input is untrusted and fully admitted. Runtime Root generation/session/epoch bindings, current-source Support binding and Native transaction tickets remain authoritative. Cache is derivative provenance, never Terrain/World truth. Cold initialization stays measured, including first full Source admission. Changed-leaf synchronization on the next Terrain cut is measured and committed on the existing same-Source mirror.

Charge bounded runtime clone and retained ancestor logical bytes in the existing Prepare and resident ledgers. No physical IPC/GPU/heap byte claim. Native cache lifetime is one World session; normal disposal and Restore replacement clear it, and Main load-rollover clears acknowledgement. No mutable TypedArray or input record is retained as trusted Source. Failure before completed recipe never installs a body or publishes Root; stale/different digest, altered material/occupancy/hash and closed owner are rejected.

Compare owned-moving-v2 against owned-terrain-v3 with identical real cold first Terrain cut followed by a lower cut of the remaining authored pillar on the same Source. Keep Moving/Save/ColdLoad qualification separate. Private render admission and all five mesh hash passes remain unchanged; this gate does not adopt a renderer or claim Main-thread unloading.
