# Capability Spec: Browser UI Input HUD Foundation v1


## Requirements

### UI-001
UI SHALL consume snapshots/ViewModels.

### UI-002
UI SHALL send explicit commands rather than mutate Core objects directly.

### UI-003
HUD SHALL display target, distance, route/plan state, replan-required, fuel and authority status.

### UI-004
TestBridge SHALL remain test-only and not become player UI architecture.
