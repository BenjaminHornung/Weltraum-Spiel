Root is sole writer. Existing Physics Owner, Compute Pool, Rapier0.12, Three0.185.1 and 0.125-m truth remain. No new Voxel authority worker. Reuse adjacent Source cursors, Recipe/compile jobs, transaction and render resource machinery. Direct read-only review is limited to bound contract/identity concerns and final review.

G0 freezes P/E and recoverable file bytes before mutation. Public issuance is not private ownedGraphs proof. E direct-v1 ancestry is not automatically P. Integration requires identical public bytes for identical input/history or the specific activation stays disabled.

D1 removes/reuses generic Init work and gives actual Source/pool acknowledgement an incarnation-bound lifetime before SceneReady. D2 preserves traversal/summation/hash semantics and separates preliminary/parent/child derivatives. D3 starts with 16^3 edit invalidation and the required halo while larger draw aggregation and current Collision remain. D4 uses one local exclusive-buffer admission boundary; old public commands stay unchanged. Bind variants/source/build/profile before every native series.

Risks: hidden TypedArray aliases, stale generations, nonlocal detach/UnknownBoundary, old/new resource coexistence, unmeasured Main host spans, and moving pose/momentum at Native Stage. Diagnostic counters are batch-level wall observations, never exclusive CPU claims. Record concrete rulings in PHASE1_DECISIONS.md.
