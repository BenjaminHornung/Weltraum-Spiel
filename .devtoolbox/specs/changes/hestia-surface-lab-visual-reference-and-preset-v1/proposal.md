# Hestia Surface Lab Visual Reference and Preset v1

## Motivation

The parallel browser Surface Lab needs a measurable Hestia visual target without repeating analysis of concept images and worldbuilding documents. Existing concept art is guidance rather than runtime evidence, and renderer output must not become gameplay or voxel authority.

## Outcome

Produce a source-audited visual reference, a human-readable preset, a machine-readable design handoff, and a concise implementation-agent handoff for preset `hestia.nebelwald-archipelago.preview.v1`.

## Scope

- Audit the ten available requested Hestia/surface concept images and document the missing requested image 41.
- Separate Direct Visual Evidence, Documented Concept Rule, Inference, Provisional, Rejected, and Deferred findings.
- Define measurable preview targets for terrain, palette, materials, vegetation, fog, water, lighting, cameras, HUD chrome, and screenshot acceptance.
- Publish in two commits so the parallel runtime branch can consume the audit early.

## Non-goals

No runtime, generator, mesher, renderer, worker, UI, test, evidence, image, binary, package, roadmap, Unity, or asset changes. No runtime import from `docs/**`. No proof of performance, gameplay truth, persistence, collision, navigation, or voxel authority.
