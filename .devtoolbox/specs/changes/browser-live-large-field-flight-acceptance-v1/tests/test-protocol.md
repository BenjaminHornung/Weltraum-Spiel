# Test Protocol

Evidence is generated by:

```powershell
npm run test:e2e -- tests/e2e/playable-large-field-live-flight.spec.ts
```

Required completion checks:

```powershell
npm run test:e2e -- tests/e2e/playable-large-field-live-flight.spec.ts
npm run test:e2e -- tests/e2e/playable-large-proving-ground.spec.ts
npm run test:e2e -- tests/e2e/autopilot-proving-ground-v2.spec.ts
npm run test:e2e -- tests/e2e/multi-obstacle-planner.spec.ts
npm run test
npm run build
git diff --check
git status --short -- Assets package.json package-lock.json apps/weltraum-browser/package.json apps/weltraum-browser/package-lock.json
```

Final command results and screenshot paths are recorded in `apps/weltraum-browser/evidence/browser-live-large-field-flight-acceptance-v1.md`.
