# Capability Spec: Unity Feature Intent Mining v1


## Requirements

### INTENT-001
Every browser port candidate SHALL have a Feature Intent Card before implementation.

### INTENT-002
Feature Intent Cards SHALL separate player outcome from Unity implementation details.

### INTENT-003
Known Unity bugs or documentation drift SHALL be captured in a bug-trap list.

### INTENT-004
Archived specs SHALL be considered, but not blindly treated as current truth.
