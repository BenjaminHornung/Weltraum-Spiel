# Capability Spec: Three.js Mainline Transition v1


## Requirements

### MAIN-001
The repository SHALL contain a documented browser-mainline decision.

### MAIN-002
Unity sources SHALL remain available as feature-intent references.

### MAIN-003
New browser gameplay work SHOULD target `apps/weltraum-browser` unless a later ADR supersedes this.

### MAIN-004
A feature copied from Unity behavior SHALL first be represented as a Feature Intent Card.
