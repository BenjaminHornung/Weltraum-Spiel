## Acceptance

Root admission decision, 17 October: keep the existing JSON format, caps and Clock policy. Use the existing tree cursor as a pure preflight before cloneability probes and source expansion. Let U=64*(objects+arrays)+16*(nodes-1), T=measured UTF16 key/value bytes, P=measured JSON UTF8 bytes of the complete V1 storage envelope, D=validated source decode working bytes, K=existing retained owner/cache data not already in the scene ledger, and Pold=the 16 MiB old-slot bound until transaction-local reading proves a smaller actual payload. Earlier metadata can be stale after another tab writes. Reserve W=R+T+8U+K+max(96 MiB,D+3P,5P+Pold) before encode/storage allocations. Eight structure generations cover live/captured/validated/canonical-envelope/repository/transaction containers conservatively; primitive immutable texts are counted by T, while separately created canonical cache texts belong to K. R excludes expired stage scratch and includes actual retained scene/source assets. This is a conservative logical allocation charge, not a JS heap measurement.

Keep the smaller synchronous capture API: an optional admission callback runs after acquiring its existing barrier and assembling the raw Factory reference DTO, but before witness strings or cloning. The early phase reserves the same expression with Factory-only tree counts and full Native96. The complete signed checkpoint is counted and admitted again before its cloneability probe and Native expansion. Cache accounting only reads existing WeakMaps and never populates them. This callback does not weaken any capture witness. Root.read must not call canBeginFactoryCheckpoint; Entry already combines that gate and Root.save checks it separately. Cold decoding reserves the exclusive full cap, then releases only genuinely unneeded aliases after their consumers adopt data and retains a separately counted live owner charge before Native96 admission. Any actual excess remains a visible rejection and requires diagnosis; Save is enabled only after this wiring and its checks.

The bounded stage-memory getter is telemetry of current committed immutable owners, not an authority capture: it may count them while construction is busy, with no Host.read recursion, Native commands, cloning or notifications. Existing stage admissions include that live owner's T+U+K alongside full Native96; Save instead includes the same owner in its full checkpoint T+8U+K and must not charge it twice. Current asset deltas against the old ledger remain included. Public cold decoding also applies its pure tree/D CPU admission before the cloneability probe: the one-million-node shape bound alone is not a memory proof. The existing separately held lastStep cache text, if present, belongs to K; only canonical serialization excludes the root lastStep, not cache ownership accounting. A full envelope fixed-width signature placeholder is permitted solely for pre-sign allocation counting, with the actual fnv1a32 signature's exact width/counts rechecked after signing.

The intentionally retained onboarding initialMaterial is also an owner. Once current material differs, K includes that initial Material DTO's one-generation T+U and its existing Dry/Production material-cache texts; it does not add the whole Domain a second time. Shared catalog identity is counted once. Cold metadata charge transfers to the adopted Factory owner before restored asset admissions, with only still-needed Native/projection data retained separately until release. The synchronous Save busy flag starts only after the genuinely confirmed Factory admission has acquired its barrier; it must never invalidate the capture's own initial Host confirmation.
