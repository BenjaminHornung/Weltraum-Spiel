# AI Agent Docs

Diese Ablage sammelt agentenbezogene Arbeitsregeln und wiederverwendbare
Prompts fuer Weltraum-Spiel.

## Dateien

- `agent-workflow-v1.md` beschreibt den repo-weiten Codex-, DevToolbox-,
  Unity-MCP- und Evidence-Workflow.
- `prompts/codex_project_structure_agent.md` ist fuer Clean-Core-Strukturarbeit
  und Boundary-Fragen gedacht.
- `prompts/codex_autopilot_v2_agent.md` ist fuer Autopilot-V2-Planungs- und
  Implementierungsslices gedacht.
- `prompts/codex_autopilot_test_range_agent.md` ist fuer Test-Harness,
  Proving-Ground- und Evidence-Aufgaben gedacht.
- `prompts/codex_ui_redesign_agent.md` ist fuer Player-UI-Redesign-Aufgaben
  gedacht.
- `prompts/codex_spec_cleanup_agent.md` ist fuer Spec-Sortierung, Backlog-
  Hygiene und DevToolbox-Strukturpflege gedacht.

Vor Runtime-Arbeit immer erst die passende DevToolbox-Spec und `AGENTS.md`
lesen.
