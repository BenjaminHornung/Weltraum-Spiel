# Native technical S0 source

`source.scene.json` is the native procedural geometry/marker source in meters; `authoring-v1.json` uses the existing Hestia authoring semantic contract. Runtime MeshArtifacts are derived by the W05 adapter, never material or structural world authority.

Ground-center frame: east +X, north +Z, height +Y. Structural authoring grid 0.25 m is separate from HVP terrain 0.125 m. Part boxes, semantic roles, support contacts, pivots, sweeps and source references are explicit. Power markers remain authoring-only. Machines consume only their previously paid BOM, not additional C09 feet.

No Blender, GLB, HVOX compiler, provider generation or package CLI execution is claimed. These are original S0 technical proxies, not visual Owner acceptance. Art review needs real later captures. Presentation geometry adds no inventory, power, collider or gameplay event.
