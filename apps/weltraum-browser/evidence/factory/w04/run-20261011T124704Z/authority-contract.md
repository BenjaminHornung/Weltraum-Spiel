Its result and payload must agree with the current full authoritative core. Normal CAS compares that complete core and current input before recomputing and comparing the complete proposed pair and derived replay. NoOp requires the entire accepted payload, matching next core/replay, exact original authority input and exactly the current native Material candidate. Changed base, material receipts, plans or work are rejected even when next-state/input labels match. Joined-field aliases and inherited data do not satisfy the own-key cardinality/membership check.

## Cache boundary

WeakSet/WeakMap caches retain only derived validation results or complete canonical strings. They use object identity only after recursive immutability, plain-record/array prototypes, data-only property descriptors and symbol exclusion. Mutable children, accessors, custom prototypes and new/external objects do not qualify. Catalog reuse requires complete source data and complete native ResourceCatalog validation; altered displayName with an unchanged claimed catalog canonical is rejected. Material reuse requires current native snapshot and exact capacity admission. No quantities, alternate cargo, mutable global world or digest-only trust enter these caches. External/JSON-restored binding and payload records are checked for exact own key sets and reparsed/recanonicalized; only internally generated immutable serializer outputs skip redundant re-parsing.
