# Hestia Cut RT V2 — review evidence

This directory contains selected **original JSON test and browser reports** from the local P00–P07 execution, including failed attempts and the complete 14-case diagnostic matrix. `MANIFEST.json` records each report's relative path, original/published SHA-256 and any explicit redaction. Reports without a redaction are byte-for-byte copies. Browser `process.json` files omit the ephemeral launch `commandLine` (including the temporary user-data directory); their remaining GPU/process data is unchanged. Playwright JSON reports can contain embedded page-only PNG attachments. Separate PNG screenshots, browser trace archives, private local tool logs, and the large preparation archive are **not** included.

The original repository base was `9341fb906383515057e659a99e16a381632f2bea`; the published branch commit is the code snapshot for review. Old reports describe the *pre-commit dirty source* and retain their original source/build SHA-256 inventories. Do not infer that their `plan.head` contains the changes: compare the published source to each raw inventory before drawing attribution conclusions. A report with a failure is evidence of a failure, not an accepted result. See [`P07-RESULT.md`](../../../../docs/research/hvp-cut-rt/P07-RESULT.md) and the [prospective follow-up](../../../../docs/research/hvp-cut-rt/CUT-COOPERATIVE-FOLLOWUP-PLAN.md).

The 14 diagnostic cases have **one sample per variant/temperature**, not a valid p95 population. Body Hold remains `null`/unmeasured; the ≥100-valid-sample-per-class/temperature, three-session, broader fault/recovery and Visual Owner gates are still open. Do not label this snapshot a release or a measured 250-ms acceptance.
